# Portfolio Astro 🚀

Proyecto de **portafolio web moderno** construido con **Astro**, **React** y **TailwindCSS**.  
Su propósito es servir como plantilla reutilizable para que cualquier desarrollador pueda crear, personalizar y desplegar fácilmente su propio portfolio online.

## 🚀 Contenido
- Generación estática rápida y optimizada con **Astro**.
- Componentes modulares en **React** para mayor flexibilidad.
- Diseño **responsive** y moderno con **TailwindCSS**.
- Preparado para SEO básico y despliegue en plataformas como **Vercel**, **Netlify** o **GitHub Pages**.

## 🛠️ Requisitos
- [Node.js](https://nodejs.org/) v18 o superior.
- Gestor de paquetes: **npm**, **yarn** o **pnpm**.
